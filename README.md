# 🔐 AutoLogin_Enable

Настройка автоматического входа в Windows без пароля.

## 🚀 Что делает

Скрипт настраивает автологин для текущего пользователя:

- 👤 Определяет текущего пользователя автоматически
- 🔑 Отключает запрос пароля на экране приветствия
- 🖥️ Применяет настройки через реестр Windows

## 📦 Использование

1. Скачай `AutoLogin_Enable.bat`
2. Запусти от имени администратора
3. Подтверди установку нажав `Y`
4. Готово! ✅

Изменения вступят в силу после перезагрузки.

## ⚠️ Требования

- Windows 10 / 11
- Права администратора

## ⚠️ Внимание

Пароль хранится в реестре в открытом виде.  
Не используйте на общедоступных компьютерах.
